# Glossary: Türkçe (tr)

Terms to keep the same across the app. Change a term here first, then in the locale file.

| English | Türkçe |
|---|---|
| part | parça |
| piece (count) | adet |
| part code | parça kodu |
| manufacturer part number | üretici parça numarası |
| storage place | saklama yeri |
| stock | stok |
| low stock | stoku azalan / düşük stok |
| import | içe aktar |
| review | inceleme |
| pack | paket ("10'lu paket") |
| units | birim |
| parts list (BOM) | parça listesi |
| schematic | şema |
| backup | yedek |
| restore | geri yükle |
| undo | geri al |
| package (footprint) | kılıf |
| supplier | tedarikçi |
| datasheet | datasheet |
| category / subcategory | kategori / alt kategori |
| Drive sync | Drive eşitleme |

Turkish counts take the singular after a number ("3 parça"). "Adet" is the count of pieces; "parça" is a kind of part. Datasheet stays English, as engineers say it.

Never translated: part codes (LM7805), units (V, A, W, Ω, µF), acronyms used as names (SMD, MOSFET, NTC, BJT, KiCad), shop names.
