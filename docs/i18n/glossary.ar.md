# Glossary: العربية (ar)

Terms to keep the same across the app. Change a term here first, then in the locale file.

| English | العربية |
|---|---|
| part | قطعة / صنف |
| piece (count) | قطعة |
| part code | رمز القطعة |
| manufacturer part number | رقم القطعة لدى المصنّع |
| storage place | مكان التخزين |
| stock | المخزون |
| low stock | مخزون منخفض |
| import | استيراد |
| review | مراجعة |
| pack | عبوة |
| units | وحدات |
| parts list (BOM) | قائمة القطع |
| schematic | المخطط |
| backup | نسخة احتياطية |
| restore | استعادة |
| undo | تراجع |
| package (footprint) | الغلاف |
| supplier | المورّد |
| datasheet | ورقة البيانات |
| category / subcategory | الفئة / الفئة الفرعية |
| Drive sync | مزامنة Drive |

Six plural forms (zero, one, two, few, many, other). Where agreement would be awkward, messages use a label with the number ("الأسطر: 5"). Part codes and numbers stay left to right inside right-to-left text.

Never translated: part codes (LM7805), units (V, A, W, Ω, µF), acronyms used as names (SMD, MOSFET, NTC, BJT, KiCad), shop names.
