# Glossary: Русский (ru)

Terms to keep the same across the app. Change a term here first, then in the locale file.

| English | Русский |
|---|---|
| part | деталь |
| piece (count) | штука, шт. |
| part code | код детали |
| manufacturer part number | номер производителя |
| storage place | место хранения |
| stock | склад / остаток |
| low stock | заканчивается |
| import | импорт |
| review | проверка |
| pack | упаковка ("упаковка по 10") |
| units | единицы |
| parts list (BOM) | список деталей |
| schematic | схема |
| backup | резервная копия |
| restore | восстановить |
| undo | отменить |
| package (footprint) | корпус |
| supplier | поставщик |
| datasheet | даташит |
| category / subcategory | категория / подкатегория |
| Drive sync | синхронизация с Drive |

Plural forms one/few/many/other: 1 деталь, 2 детали, 5 деталей. Where a noun after a number is awkward, a label with a colon is used ("Строк: 5").

Never translated: part codes (LM7805), units (V, A, W, Ω, µF), acronyms used as names (SMD, MOSFET, NTC, BJT, KiCad), shop names.
