# Glossary: 简体中文 (zh-CN)

Terms to keep the same across the app. Change a term here first, then in the locale file.

| English | 简体中文 |
|---|---|
| part | 元件（种） |
| piece (count) | 件 |
| part code | 型号 |
| manufacturer part number | 厂商型号 |
| storage place | 存放位置 |
| stock | 库存 |
| low stock | 库存不足 |
| import | 导入 |
| review | 审核 |
| pack | 包（每包 10 件） |
| units | 单位 |
| parts list (BOM) | 元件清单 |
| schematic | 原理图 |
| backup | 备份 |
| restore | 恢复 |
| undo | 撤销 |
| package (footprint) | 封装 |
| supplier | 供应商 |
| datasheet | 数据手册 |
| category / subcategory | 分类 / 子分类 |
| Drive sync | Drive 同步 |

Chinese has one plural form. "种" counts kinds of parts, "件" counts pieces. Full-width punctuation in Chinese sentences; part codes keep half-width.

Never translated: part codes (LM7805), units (V, A, W, Ω, µF), acronyms used as names (SMD, MOSFET, NTC, BJT, KiCad), shop names.
