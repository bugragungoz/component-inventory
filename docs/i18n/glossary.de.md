# Glossary: Deutsch (de)

Terms to keep the same across the app. Change a term here first, then in the locale file.

| English | Deutsch |
|---|---|
| part | Teil |
| piece (count) | Stück |
| part code | Teilecode |
| manufacturer part number | Herstellerteilenummer |
| storage place | Lagerort |
| stock | Bestand |
| low stock | wenig Bestand |
| import | Import / importieren |
| review | Prüfung |
| pack | Packung ("10er-Packung") |
| units | Einheiten |
| parts list (BOM) | Stückliste |
| schematic | Schaltplan |
| backup | Sicherung |
| restore | wiederherstellen |
| undo | rückgängig machen |
| package (footprint) | Gehäuse |
| supplier | Lieferant |
| datasheet | Datenblatt |
| category / subcategory | Kategorie / Unterkategorie |
| Drive sync | Drive-Abgleich |

Address the user with "Sie". Keep sentences short; German runs about 30 % longer than English.

Never translated: part codes (LM7805), units (V, A, W, Ω, µF), acronyms used as names (SMD, MOSFET, NTC, BJT, KiCad), shop names.
