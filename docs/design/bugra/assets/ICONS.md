Single-ink outline icons on a 24px grid, drawn in `muted` dark (#a29b91) because an image cannot inherit color; use the inline versions inside the components when the icon must follow the theme.

- `globe.svg`, `chevron-down.svg`, `close.svg`, `check.svg`: 1.6px or 1.8px stroke, round caps, ink #a29b91. Use in dark theme; recolor the stroke for light.
- `mail.svg`: filled glyph, ink #a29b91.
- Sizes in use: 15px globe, 16px close, 18px social, 19px nav.
