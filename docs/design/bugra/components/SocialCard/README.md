# SocialCard

The social preview image: warm black `bg`, a muted name line top-start, an `og-title` headline with the subject phrase in `accent`, an `og-sub` line, and an `accent` address pill bottom-end. One soft green glow in the top-end corner.

- The glow is the only gradient in the system, allowed only here.
- The headline shrinks per language (82px Latin down to 66px Japanese) and drops negative tracking for Arabic and CJK.
- Rendered at 1200x630; the component scales it with `scale`.
