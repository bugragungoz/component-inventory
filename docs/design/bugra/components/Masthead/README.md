# Masthead

The sticky top bar: wordmark on the start side, navigation on the end side, a `line` rule beneath and a blurred `bg` at 88% behind it.

- Pass the `Wordmark` as `wordmark` and text links, the language menu and icon buttons as children.
- Keep it to one row down to 320px: on narrow screens the language menu collapses to its globe and the promo bar is what shrinks first.
- Every child is at least 48px tall (`target-min`), inside a 58px bar.
