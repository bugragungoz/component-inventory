# IconButton

A round, transparent icon button in `muted` that turns `ink` on a `surface-2` fill on hover.

- `label` is required: it becomes the accessible name.
- Icons are single-stroke outline SVGs (or filled brand marks) that inherit `currentColor`; 19px in the masthead, 18px in the footer, 16px in the small size.
- The hit area is 48px (34px in the `sm` size, used only inside dense bars).
