# Snackbar

A `surface-2` bar with `radius-sm` and `shadow-menu` for one short status line and at most one text action in `accent-ink`.

- Added from Material 3; the source only confirms in place (Copy -> Copied). Use it for results not tied to a control.
- Name the action the same way the button did: "Published", with the action "Undo".
- Role `status`; auto-dismiss after 4-10 seconds, never while it holds an action the user is reading.
