# LanguageMenu

A `details`/`summary` menu that lists every language by its own name, with the current one marked by a check and `accent-ink`.

- No script is needed to open it; it only adds close-on-Escape and close-on-outside-click.
- Each row carries its own `lang` so it reads in its own direction; keep the list order stable (default language first).
- Below 480px the button shows only the globe and the list is pinned to the page gutters.
