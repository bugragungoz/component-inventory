# CodeBlock

A `code-bg` block with a label and a `CopyButton` in its bar, `code` type inside, always left-to-right even on right-to-left pages.

- Use `prompt` for long text: it wraps and scrolls at 380px instead of scrolling sideways.
- The label names what is inside ("prompt.txt", "terminal").
- Comments and labels use `code-muted`; text is `ink`.
