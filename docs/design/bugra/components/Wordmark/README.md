# Wordmark

The name in `wordmark` type, optionally preceded by a small outline monitor glyph drawn in `accent-ink`.

- One per page, in the masthead. Pass `href` to make it a link.
- The glyph is a plain outline box with a stand line; it is a placeholder mark, replace it with your own if you draw one, or pass `mark={false}` to show the name alone.
- No logo file ships with this system; never redraw a third-party logo here.
